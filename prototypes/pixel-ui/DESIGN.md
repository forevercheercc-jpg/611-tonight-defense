# 611 今晚守家 · 像素 UI 原型

本地打开 `index.html` 即可预览。页面及字体、人物、场景均在本目录，浏览时无需联网。

这版交付包含五个主要界面、英雄详情、装备强化和路线面板。战斗使用演示状态与演出脚本，尚未连接正式微信对局或联机服务。

## 视觉基准

- 以 390 × 844 竖屏为基准，场景和界面使用整数像素定位。画布以两倍分辨率输出。
- 深夜校园礼堂作为统一场景。蓝灰石砖与拱门承接既有赤灯礼堂章节，暖色灯火保留寝室夜晚的气氛。
- 人物使用约 36 × 40 原生像素。图鉴按整数倍放大，副路观察使用半尺寸缩略。
- 使用硬边轮廓、切角边框、三档明暗和块状碎片。生命、技能、金币分别使用青绿、浅蓝和暖黄，危险使用珊瑚红。
- 中文使用 Fusion Pixel 12px 字体，标题使用 24px。字体文件约 669KB，完整许可在 `fonts/` 中。
- 英雄体型、种族和职业轮廓参考多多自走棋官方英雄库，人物、武器和场景以代码重新绘制。六位室友保留独立配色与专属武器。[多多自走棋官方英雄库](https://ac.dragonest.com/zh-cn/charactor)

## 五个主要界面

| 界面 | 展示内容 | 可验证的操作 |
| --- | --- | --- |
| 三路守城 | 第9波，7人阵容，三路同时显示 | 点击路线观察、伙伴详情、四类战斗反馈 |
| 波间备战 | 第7波，6人上限，5卡商店、8格备战席 | 买第三张敖犬升2星、刷新、锁定、换位与替换 |
| 英雄与羁绊 | 场上不同英雄计数、生效档位、下一档缺口 | 翻页查看全部标签、返回战场 |
| 高地首领战 | 第10波赤灯指挥官、司礼官复苏、全队集结 | 控制伙伴打断，清理随从后的解除保护演出 |
| 像素英雄图鉴 | 当前19位英雄及其种族、职业、技能 | 逐个切换，查看大尺寸像素形象 |

英雄详情可进入装备强化，装备与升级各花费4金币，最高2级，每个伙伴装备一件。装备参数和升星保留规则沿用当前游戏。演出伤害为示意值。

## 打击反馈

| 反馈 | 演出设计 |
| --- | --- |
| 近战普攻 | 接敌前移，攻击姿态，阶梯刀弧，约45毫秒命中停顿，2px短震与金色碎片 |
| 反击螺旋 | 以敖犬为中心绘制双层旋转弧、向外碎片和多目标伤害数字 |
| 一杖断灯 | 从唐卵连到多个怪物，闪电折线逐段变化，战场局部压暗，单位保留可见轮廓 |
| 治疗 | 青绿环形脉冲、向上加号、独立治疗数字，前排生命条实际回升 |
| 升星 | 三合一后原位置模型保留，双星提示，金色环与碎片短暂出现 |
| 首领读条 | 红色危险边界、5秒读条、青绿打断机会，成功后即时中断反馈 |
| 读条完成 | 未及时打断时展示援军抵达，回到首领场景可重新预览 |

原型外围的四个特效按钮用于检查演出。英雄技能在正式玩法中自动触发，首领打断保留操作入口。音效使用本地合成短音，默认关闭。支持暂停与减弱震动。

## 交互约束

- 相同英雄、相同星级三合一，最高3星。场上与备战席共同参与，合成优先保留场上位置和第一件装备，多余装备返还金币。
- 备战席满员时，仍允许购买可立即合成的第三张伙伴，结算后恢复八格。
- 第7波人数上限6，第8波起上限7。阵型前四格与后三格保持原规则。
- 允许点击两格换位。备战席与阵型之间直接替换作为拟议交互，需在后续正式版本接入。
- 羁绊只计算上阵不同英雄，面板可分页查看所有标签。当前未接入的效果直接标注。
- 打断需要场上有岩之灵、海象拳王、光羽弩手或刺魂者之一。移走全部控制伙伴后，打断入口消失。
- 商店锁定展示当前锁定状态。原型的波间场景固定，跨波保留由正式游戏规则实现。
- 路线面板可观察三路，回城入口播放演出。原型使用固定中路队伍，未连接实际移动和占点规则。

## 当前范围

本轮完成可点击的视觉与反馈原型。联机房间、交换、Roll战利品、排行榜与存档不在本次五屏原型范围中，已有正式玩法仍按当前项目运行。

最小预览宽度320px已检查无横向溢出。窄屏采用整幅缩放，八格备战席的触控面积随之缩小，正式手机适配需要结合实际设备调整。

原型位于独立目录。现有 `minigame/` 和 `server/` 文件保持本轮开始时的状态。
