# 611：今晚守家 · 剧情与关卡分布

## 故事主线

毕业多年后，六位室友约好回学校聚一聚。走到宿舍楼下时，旧礼堂的灯突然亮起，校园里出现不属于现实的回廊和巡逻者。原来当年六人一起留下的回忆，被一台失控的旧放映机投射成了「回声世界」。它吸收了大家熟悉的奇幻冒险想象，也把未说完的话放大成怪物。六人要找回散落的回忆碎片，修复放映机，才能让校园恢复原样。

故事以原创校园奇幻为主，怀旧游戏体验作为气氛参考。人物、地图、首领和道具采用 611 自己的设定。

## 游戏中如何呈现

- 每关用「进入场景 → 认识目标 → 探索岔路 → 救室友或修机关 → 首领战 → 离开」的节奏，主路清楚，支线奖励有风险和价值。
- 小地图只显示已发现区域；任务提示先给方向，再给更具体的位置。首领攻击需有明确预警与躲避机会。
- 武器拾取时展示变化并替换手持外观，攻击方式各有特点。死亡后可在本层复活，保留装备和训练成长，本层敌人、机关与补给重置，金币有损失。
- 同一套世界观贯穿剧情和三路守城：剧情中揭开的礼堂与黑塔危机，成为守城副本的背景。PVP 作为室友之间的演习，不改变主线故事。
