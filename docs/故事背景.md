# 611 今晚守家：故事背景与创作约定

状态：供后续创作使用的初版设定；校园地点与室友昵称以大家回忆为准。剧情、多人和多数对话尚未实装。

## 故事主线

多年后，611 的室友因一次相聚重新想起大学生活。寝室的灯光一闪，他们熟悉的校园在记忆中变成一座奇幻战场：楼道化作防线，散落的记忆变成可以并肩作战的伙伴。奇怪的怪物沿三条路线逼近，大家决定一起守住 611 的灯。

这是一场共同的奇幻回忆，不是对真实校园或室友经历的逐项记录。每章围绕一处校园回忆展开，通关后慢慢拼回 611 的故事。剧情和敌人原创，只借鉴多人副本、团队冒险的气氛。

## 玩家与伙伴

真人玩家是参与这场回忆的室友；抽卡得到的是由回忆凝成的「伙伴」，不是现实里出现多个同一位室友。相同伙伴合成表示同一段回忆变得更清晰，进而增强技能。玩家不必选择某一名室友扮演，六位室友也可以作为伙伴出现在阵容中。单人时由电脑队友补位；多人玩法尚未实装。

## 战场与来敌

- 611 是大家共同守护的记忆坐标。三条路线是通往它的奇幻道路，具体地图不宣称是学校的真实布局。
- 怪物是回忆世界中出现的奇幻威胁。它们从道路涌来，穿过防线会威胁基地；防线失守后向高地退守。
- 小树林和大电灯泡是校园回忆中的喜剧彩蛋。相关约会玩笑不指向真实具体人物，可在后续故事里与唐卵的「一杖断灯」呼应。
- 赤灯礼堂的首领是赤灯指挥官，赤灯司礼官会尝试复苏卫士。黑塔之巅的首领是裂翼守望者，升空时由两侧余烬火灵保护。第五波后大家自动回高地，击败首领后还要处理路上的怪物。
- 金币、装备和合成是本局的奇幻冒险资源；不解释为现实中的物品或真实人物经历。

## 六位室友伙伴

| 伙伴 | 形象和技能方向 | 记忆彩蛋 |
| --- | --- | --- |
| CSY | 越战越勇的重装战士 | 守住阵线，和室友并肩战斗 |
| 敖犬 | 挨打积攒能量、旋转反击的守卫 | 「都来干我！真爽呀！」 |
| 志兵 | 护盾吸收伤害后爆发的守卫 | 「看本班长的千手观音！」 |

| 歌姬 | 连续追击残血敌人的刺客 | 「小贱一下！」；昵称早前也写过「戈姬」，最终写法待确认 |

六名不同室友组成 611 羁绊时，可触发大家接话的合击彩蛋。数值和各技能细节以玩法设计及实际实现为准。

## 章节创作方法

首章「重返 611」从灯光闪烁开始，介绍三路守城和首领，结束于守住寝室的灯。后续章节可使用武汉软件工程职业学院的真实楼宇、路线和大家的经历作为灵感；具体楼名、建筑位置、事件发生顺序及人物细节须由室友回忆确认，暂不编造为事实。每章保持校园日常、奇幻战斗和 611 式玩笑相结合。

## 文案与美术约定

- 整体温暖、轻松，战斗可以紧张，首领可以有压迫感，笑点来自室友之间的熟悉感。
- 奇幻世界、伙伴、怪物、装备名称和素材使用原创表达；不直接使用其他作品的人物、图像、音乐或剧情。
- 副本使用「赤灯礼堂」「黑塔之巅」及各自首领的原创称呼。需要改名时同时检查界面、规则和文档。
- 游戏表现以可读为先：暗屏效果不能遮住危险、按钮和路线。
- 新章节、角色和装备需能解释其在校园回忆世界中的位置，不随意改变六人关系或把猜测写成真实经历。
