# 611 联机房间原型

联机试玩范围和共同战斗的实施顺序见 [联机试玩目标](联机试玩目标.md)。

目前实现的是房间服务基础，游戏界面还没有接入房间；房间不能开始战斗。现有单人试玩不受影响。房间和身份只保存在服务进程内，重启即丢失。

本机安装 Node.js 后，可在项目目录运行 `node server/index.js`，服务默认只监听本机 127.0.0.1:6110。接口支持创建、加入、查询、准备和离开，最多 6 人，房主离开时移交房主；房间 30 分钟没有请求会过期。

`minigame/room-client.js` 是微信请求适配器，尚未接入界面。实际手机联机还需要部署可访问的 HTTPS 服务、设置微信合法请求域名、验证身份并实现房间界面、断线恢复和服务端共同战斗。请勿把当前开发用房间服务直接公开到互联网。
